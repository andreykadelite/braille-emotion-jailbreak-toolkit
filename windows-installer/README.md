# Windows-установщик

Установщик собирается в один EXE и не требует Python или ADB на компьютере пользователя. Внутри находятся PyQt5, Android Debug Bridge, основной APK и мост для заводского меню.

Окно показывает найденные устройства и отдельный итоговый статус: диспетчер установлен полностью, установлен частично, отсутствует либо устройство ещё не готово. RuStore и другие сторонние программы в расчёте статуса не участвуют.

Операции установки и удаления доступны только для проверенного B340. Перед изменением устройства пользователь должен принять предупреждение об ответственности. Все долгие операции выполняются вне потока интерфейса; журнал, индикатор выполнения и доступные действия обновляются во время работы.

Клавиатурная проверка охватывает порядок Tab, имена и описания элементов, сохранение фокуса, диалоги подтверждения и живую область состояния. Автоматические тесты находятся в `tests/`.

Команда полной сборки приведена в [docs/BUILD-RU.md](../docs/BUILD-RU.md).
