# Участие в проекте

Сообщение об ошибке должно содержать модель eMotion, версию Android, версию набора, точные шаги и текст журнала Windows-установщика. Перед публикацией удалите из журнала серийный номер устройства, имена личных файлов и другие личные данные.

Для изменения кода:

1. Создайте отдельную ветку от `main`.
2. Не добавляйте в Git заводские APK, прошивки, ключи подписи, токены, журналы устройства и результаты декомпиляции чужих приложений.
3. Запустите Python-тесты и проверку встроенных файлов.
4. Если менялся Android-код, соберите оба APK и проверьте навигацию на настоящем Braille eMotion.
5. Опишите в pull request, что изменилось, как это проверялось и какие риски остаются.

Новые элементы интерфейса должны иметь понятное имя для скринридера, предсказуемый порядок Tab и полное управление без мыши или сенсорного экрана.

Инструкция по подготовке среды находится в [docs/BUILD-RU.md](docs/BUILD-RU.md).
