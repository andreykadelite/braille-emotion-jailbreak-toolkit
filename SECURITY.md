# Безопасность

Если вы нашли уязвимость, не публикуйте рабочий эксплойт и данные устройства в открытом issue. Отправьте владельцу репозитория приватное сообщение через функцию GitHub «Report a vulnerability», если она доступна. Если приватная форма недоступна, создайте issue без технических подробностей и попросите способ защищённой связи.

Укажите затронутую версию, ожидаемый результат, фактическое поведение и минимальные шаги воспроизведения. Не прикладывайте токены, ключи подписи, серийные номера и полный ADB-журнал без очистки.

Поддерживается последняя опубликованная версия. Исправление выпускается после подтверждения проблемы и проверки на устройстве.
