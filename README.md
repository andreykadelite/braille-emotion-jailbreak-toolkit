# Braille eMotion Jailbreak Toolkit

Набор добавляет на Braille eMotion доступный диспетчер сторонних Android-приложений, не заменяя заводскую оболочку. В комплект входят исходный код Android-приложения и один автономный EXE для Windows. EXE сам находит подключённое устройство, показывает состояние диспетчера, устанавливает его или полностью удаляет.

Слово «jailbreak» здесь используется в бытовом смысле: владелец расширяет возможности своего устройства через штатную USB-отладку Android. Root-доступ, разблокировка загрузчика, изменение прошивки и обход защиты содержимого не применяются.

## Что получает пользователь

- «Диспетчер приложений» с меню запуска, удаления и установки APK из `/sdcard/Download`;
- автоматический список установленных программ вместо отдельных ярлыков для каждого APK;
- управление клавишами, последовательный фокус и объявления для скринридера;
- русскую справку, которую можно читать по одному абзацу;
- ярлык в совместимом разделе заводской оболочки;
- Windows-установщик со встроенным ADB, журналом и подсказками по исправлению ошибок.

Наличие RuStore или другого магазина не требуется и не проверяется. Заводское устройство может содержать только штатные приложения. Текущее состояние определяется по двум компонентам проекта: `org.brailleemotion.appmanager` и мосту `com.selvashc.shortcut.appmanager`. Ранний тестовый пакет `com.selvashc.appmanager`, если он остался после старой сборки, помечается отдельно и удаляется при установке или очистке.

## Совместимость

Основная проверка выполнена на Braille eMotion 40 B340 с Android 12. Android-приложение требует Android 8.0 или новее (`minSdkVersion 26`). Windows-установщик собирается для 64-разрядных Windows 10 и 11.

Поддержка других моделей не обещана: установщик сверяет модель и останавливается, если подключённое ADB-устройство не похоже на Braille eMotion B340.

## Быстрый запуск

1. Откройте страницу [последнего релиза](https://github.com/andreykadelite/braille-emotion-jailbreak-toolkit/releases/latest) и скачайте `Braille-eMotion-AppManager-Setup-2.0.exe`.
2. Сверьте SHA-256 с файлом `SHA256SUMS.txt` из того же релиза.
3. На eMotion включите USB-отладку и подключите устройство кабелем с передачей данных.
4. Запустите EXE. В предупреждении об ответственности установите флажок только после чтения текста.
5. Дождитесь состояния «Устройство готово», затем нажмите «Установить диспетчер приложений».
6. Если eMotion впервые подключён к этому компьютеру, подтвердите отпечаток RSA для USB-отладки на самом устройстве.
7. После сообщения об успехе откройте заводское меню и выберите «Диспетчер приложений».

EXE не требует отдельно установленного Python, PyQt5, Android Studio или ADB. Windows может показать предупреждение SmartScreen, потому что файл не подписан коммерческим сертификатом. Не отключайте защиту целиком: сравните контрольную сумму и разрешите запуск только для проверенного файла релиза.

Полная последовательность установки, удаления и восстановления описана в [руководстве пользователя](docs/USAGE-RU.md).

## Состав репозитория

- `app-manager/` — исходники Android-приложения версии 1.5;
- `windows-installer/` — исходники доступного установщика версии 2.0, тесты и встроенные файлы;
- `scripts/` — сборка APK, подготовка содержимого EXE и полная релизная сборка;
- `docs/` — работа с устройством, архитектура, тестирование и сборка.

Заводские APK, прошивки, закрытые библиотеки SELVAS/HIMS и сторонние магазины в репозиторий не включены.

## Сборка из исходников

Для APK нужны Android SDK Platform 34, Build-Tools 36.1.0 и JBR/JDK из Android Studio. Для EXE нужен 64-разрядный Python 3.11. Скрипт создаёт отдельное виртуальное окружение и устанавливает закреплённые версии PyQt5 и Nuitka 4.1.3.

```powershell
git clone https://github.com/andreykadelite/braille-emotion-jailbreak-toolkit.git
cd braille-emotion-jailbreak-toolkit
powershell -ExecutionPolicy Bypass -File .\scripts\build-release.ps1 -RebuildApks
```

Подробности, включая подпись APK, обновление ADB, тесты и ограничения воспроизводимости, приведены в [инструкции по сборке](docs/BUILD-RU.md).

## Риски и гарантия

Установка стороннего ПО меняет конфигурацию устройства. Ошибочный или вредоносный APK способен повредить данные, нарушить работу специальных возможностей или привести к сбросу. Условия гарантии зависят от производителя, продавца и вашей страны; до изменения устройства проверьте свои гарантийные документы.
