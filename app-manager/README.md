# Android-приложение

«Диспетчер приложений» (`org.brailleemotion.appmanager`) — обычное Android-приложение без root-доступа. Оно строит список запускаемых программ, открывает системное удаление и передаёт выбранный APK из папки Download штатному установщику Android.

Приложение не удаляет и не устанавливает пакеты без системного подтверждения. Из списка удаления исключены системные пакеты, заводская оболочка, сам диспетчер и пакеты SELVAS/HIMS.

Интерфейс состоит из стандартных Android-кнопок. После смены экрана фокус ставится на первый рабочий пункт. Поддерживаются стрелки, Enter, пробел, Home, End, Page Up, Page Down, Back и Escape. Название, положение в списке и назначение элемента передаются скринридеру через content description и события доступности.

Сборка выполняется скриптом `scripts/build-app-manager.ps1`; Gradle не требуется. Требования и команды указаны в [docs/BUILD-RU.md](../docs/BUILD-RU.md).
