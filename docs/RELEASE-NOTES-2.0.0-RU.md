# Braille eMotion Jailbreak Toolkit 2.0.0

Первый публичный выпуск объединяет доступный «Диспетчер приложений» для Braille eMotion и автономный установщик для Windows.

Windows-программа сама ищет подключённый B340, различает полную, частичную и отсутствующую установку, показывает журнал и предлагает только два действия: установить компоненты проекта либо удалить их. Наличие RuStore не требуется и на статус не влияет. ADB, APK и необходимые библиотеки уже находятся внутри EXE.

Android-приложение автоматически собирает список запускаемых программ, открывает безопасное системное удаление и устанавливает обычные APK из `/sdcard/Download`. Длинные списки полностью доступны с клавиатуры. Русская справка читается по абзацам и начинается с ответственности и условий гарантии.

## Файлы

- `Braille-eMotion-AppManager-Setup-2.0.exe` — рекомендуемая установка и удаление с Windows;
- `Braille-eMotion-AppManager-1.5.apk` — основной Android-пакет для ручной установки;
- `Braille-eMotion-Factory-Menu-Shortcut-1.0.apk` — мост для ярлыка в заводском меню;
- `SHA256SUMS.txt` — контрольные суммы всех трёх файлов.

Для обычного пользователя нужен только EXE и файл контрольных сумм. Два APK опубликованы для проверки и ручной установки разработчиком.

## Перед запуском

Сохраните важные данные и прочитайте [руководство пользователя](https://github.com/andreykadelite/braille-emotion-jailbreak-toolkit/blob/v2.0.0/docs/USAGE-RU.md). Установка сторонних приложений меняет программную конфигурацию устройства и может повлиять на данные, стабильность и гарантийное обслуживание.

EXE не подписан коммерческим сертификатом, поэтому Windows SmartScreen может запросить дополнительное подтверждение. Скачивайте файл только из этого релиза и сверяйте SHA-256.

Проверенная конфигурация: Braille eMotion 40 B340, Android 12, 64-разрядная Windows 10/11. Другие модели установщик намеренно блокирует.
